# Squat angle analysis

This MATLAB project compares joint kinematics during parallel and deep squat
trials. It plots the first and last 10 seconds of ankle, knee, hip, and pelvis
angles and can optionally animate the corresponding lower-body marker data.

The committed Vicon CSV exports contain three named sections. The analysis reads
`Model Outputs` and `Trajectories` by name instead of depending on fragile raw
file-row numbers.

## Data

- `reg_squat.csv`: parallel-squat trial with 8,354 model-output and trajectory
  frames at 200 Hz.
- `dep_squat.csv`: deep-squat trial with 8,672 model-output and trajectory
  frames at 200 Hz.

The analysis uses 16 lower-body markers (48 XYZ columns) and the documented
Vicon joint-angle columns. The first and last windows each contain 2,000 samples.

## Requirements

- MATLAB R2023b or a compatible release.
- Signal Processing Toolbox for `butter` and `filtfilt` in `filterdata.m`.

`TwoDangleNew.m`, `unitvec.m`, the Vicon reader, window extraction, and geometry
helpers use base MATLAB only. The angle calculation no longer depends on
`vrrotvec` or Aerospace Toolbox.

## Run the analysis

Open MATLAB in the repository root and run:

```matlab
squat_analysis
```

The script validates all section sample rates and required angle/marker columns,
filters marker trajectories at 15 Hz, and opens four comparison figures.

Animation is disabled by default because it renders many 3-D frames. Enable it
explicitly with:

```matlab
squat_analysis(true)
```

`animationFrameStep` controls decimation; larger values render fewer frames.
The committed GIF and JPEG files are historical sample outputs and are not
regenerated by the fast test workflow.

## Test

The unit tests use synthetic geometry and a tiny temporary Vicon-style fixture;
they do not load the two large CSV files, draw figures, or run the animation:

```matlab
results = runtests('tests');
assertSuccess(results);
```

The tests cover vector normalization, exact paired-vector angles, deterministic
cylinder geometry, invalid endpoints, joint-window boundaries, marker mapping,
stick-figure assembly, named-section CSV parsing, and filter validation.

## Repository structure

- `squat_analysis.m`: analysis entry point and plots.
- `readViconSection.m`: named-section parser for concatenated Vicon CSV exports.
- `extractJointAngleWindows.m`: first/last joint-angle windows.
- `extractLowerBodyMarkers.m`: marker-column mapping and pelvis centers.
- `buildStickFigureData.m`: ordered animation matrices.
- `filterdata.m`: validated zero-lag Butterworth filtering.
- `TwoDangleNew.m`, `unitvec.m`: toolbox-free vector angles.
- `StickFigure1.m`, `cylinder2p.m`: deterministic 3-D visualization.
- `tests/TestSquatHelpers.m`: fast MATLAB regression tests.

## Interpretation

This repository is an exploratory single-subject visualization. It does not by
itself establish clinical thresholds, injury risk, or population-level effects.
Confirm marker definitions, coordinate conventions, and angle signs before
adapting the analysis to another Vicon model or export layout.
